## 📖 Что это

Бот работает на Raspberry Pi у вас дома и **читает инвертор Deye напрямую по локальной сети**, через Wi-Fi-стик Solarman. Облако Solarman, приложения и подписки для этого не нужны.

Бот пишет **только когда что-то важное**: пропал свет, появился свет, батарея садится, ошибка инвертора. Всё остальное он показывает по командам и кнопкам, без спама.

> 🧪 Проверено на **Deye SUN-5K-SG06LP1** + батарея **Deye SE-F5 Pro-C**, Raspberry Pi 4, Киев (ЯСНО).
> С другими однофазными Deye SG0xLP1 (SG01/03/04/05/06) карта регистров та же.

## 🆕 Что нового

- **📊 /status:** свет есть / нет **с какого времени** и сколько уже; сумма из сети в кВт и амперах по мощности сети инвертора.
- **💰 /finance:** отдельная строка **⚙️ «Сам инвертор»** — его собственное потребление и потери; заряд батареи — только если был; кнопка «Вчера».
- **🌡 /climate:** история раз в 10 минут, **стрелки ↗↘ за час**, графики температуры и влажности за сутки и неделю; датчики, которые облако Tuya не описывает, ловятся по MQTT.
- **🔌 «Это я выключил»:** если инвертор выключен специально, бот не беспокоит, пока он не включится.
- **🔥 Бойлер:** «обесточен — света нет» вместо «нет связи», запасной путь через облако Tuya, `BOILER_CONTROL=0` — только учёт.
- **🧹 /clean:** очистка чата одной кнопкой.
- **🔋** «Батарея почти полная» вместо ложного «не заряжается», когда свет дали при ≥ 95%.

## ✨ Возможности

### 🔔 Уведомления (приходят сами)

| | Событие | Что в сообщении |
|---|---|---|
| 🔴 | **Свет пропал** | заряд батареи, на сколько хватит при текущей нагрузке, дотянет ли до включения по графику |
| 🟢 | **Свет появился** | сколько не было света, мощность и ток заряда, время до 100%, **успеет ли зарядиться до следующего отключения** |
| 🪫 | **Батарея садится** | пороги 50 / 30 / 20% во время отключения |
| ✅ | **Батарея заряжена** | 100% (после трёх подтверждений, без ложных срабатываний). Если свет дали при ≥ 95% — «почти полная», без ложной тревоги |
| 📅 | **График изменился** | было → стало |
| ⚠️ | **Большая нагрузка** | при работе от батареи, с подсказкой выключить мощные приборы |
| 🚨 | **Ошибка инвертора** | код F01–F64 **с расшифровкой и советом** по мануалу Deye, ошибки BMS |
| 📡 | **Нет связи с инвертором** | больше 5 минут, один раз. Кнопка **«🔌 Это я выключил»** — бот молчит, пока инвертор не включится |
| 🔥 | **Бойлер** | выключен при пропадании света, включён при появлении (можно отключить: `BOILER_CONTROL=0`) |

### 💬 Команды и кнопки

| Команда | Что показывает |
|---|---|
| `/status` | **свет есть / нет с какого времени**, батарея, нагрузка, сумма из сети в кВт и амперах, прогноз, окна отключений на сегодня и завтра, «Подробнее» (температуры, Raspberry Pi, версия) |
| `/finance` | 💰 **деньги за свет**: квартира, заряд батареи, **сам инвертор**, бойлер, ночь и день по тарифу; сегодня / вчера / 7 дней / месяц |
| `/boiler` | 🔥 бойлер: греет сейчас или нет, сколько потрачено, список нагревов; вчера / 7 дней / месяц; график |
| `/climate` | 🌡 температура и влажность по комнатам, **стрелки ↗↘ за час**, графики за сутки и неделю |
| `/report` | отчёт за день / неделю / месяц: часы без света, энергия, стоимость, прогноз |
| `/graph` | картинка: свет есть/нет, заряд батареи, нагрузка за сутки или неделю |
| `/clean` | 🧹 очистить чат: только запросы и ответы или всё (Telegram разрешает удалять сообщения моложе 48 ч) |
| `/logs`, `/restart` | лог бота и перезапуск прямо из Telegram |
| 🔋 **Батарея** | последний заряд, циклы, реальная ёмкость по истории, «пора калибровать» |

## 🧰 Что нужно

### Обязательно

| | Устройство | Комментарий |
|---|---|---|
| ⚡ | **Инвертор Deye** однофазный гибрид **SUN-xK-SG0xLP1** | 3–8 кВт, низковольтная батарея 48 В |
| 📶 | **Wi-Fi-стик Solarman** (LSW-3 / LSW-5) | обычно идёт с инвертором. Нужен открытый локальный порт **8899**; на некоторых новых прошивках его закрывают |
| 🍓 | **Raspberry Pi** 3B+ / 4 / 5 / Zero 2 W | или любой Linux-компьютер, который работает 24/7. Хватит 1 ГБ RAM и карты от 16 ГБ |
| 🔌 | **Питание Pi и роутера от выхода инвертора** | иначе при отключении света бот замолчит именно тогда, когда нужен |

### Для бойлера: учёт и (по желанию) автоматическое выключение

| | Устройство | Комментарий |
|---|---|---|
| 🔥 | **Wi-Fi-розетка Tuya / Smart Life с измерением мощности** | **на 16 А**: бойлер 1,5–2 кВт — это длительная нагрузка. Проверено на **T34-Smart Plug+**. Нужна именно модель Wi-Fi с локальным управлением (почти все Tuya Wi-Fi), а не Zigbee |

> ⚠️ **Безопасность.** Бойлер нагружает розетку часами. Берите розетку с запасом по току (16 А, ≥ 3,5 кВт), не включайте её через удлинитель и тройник. Для бойлеров мощнее 2 кВт надёжнее **Tuya Wi-Fi-реле на DIN-рейку с измерением мощности**, которое ставит электрик.

> 💡 Если бойлер подключён мимо инвертора (к сети напрямую), во время отключения розетка обесточена — бот так и пишет: «обесточен — света нет». Когда свет вернётся, розетке нужно до минуты, чтобы выйти на связь. Только учёт без переключения: `BOILER_CONTROL=0`.

### Для климата: температура и влажность

| | Устройство | Комментарий |
|---|---|---|
| 🌡 | **Wi-Fi-датчики температуры и влажности Tuya / Smart Life** | любые, что работают в приложении Smart Life. Читаются через облако Tuya, поэтому нужен интернет |

> Датчики, которые показывают данные в Smart Life, но не отдают их в облачном API, бот тоже ловит: он слушает облачные сообщения (MQTT) и запоминает последние показания.
> Bluetooth-датчики без шлюза работать не будут: их видит только телефон.

### Необязательно

- **[healthchecks.io](https://healthchecks.io)** (бесплатно): пришлёт уведомление, если Pi или интернет дома пропали.

## 🚀 Установка

### ⚡ Быстрая установка — мастер

Подготовьте Raspberry Pi с **Raspberry Pi OS (64-bit)** и доступом по SSH (как это сделать — шаг 1️⃣ ниже). Затем одна команда:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/famofa24/deye-telegram-bot/main/install.sh)
```

Мастер сам по шагам:

| Шаг | Что делает | От вас |
|---|---|---|
| 1 | ставит Python и библиотеки, скачивает бота в `~/deye-tg` | пароль `sudo` |
| 2 | проверяет токен Telegram и **сам узнаёт ваш chat_id** | токен от @BotFather, нажать **Start** в боте |
| 3 | **ищет Wi-Fi-стик инвертора в сети** и сразу читает инвертор | серийник с наклейки стика, если стик его не сообщил |
| 4 | батарея, мощность инвертора, тариф, вводной автомат | ответить на вопросы (Enter — значение по умолчанию) |
| 5 | график ЯСНО по вашей черге | номер черги |
| 6 | *необязательно:* вход в Tuya по QR, **находит розетку бойлера и её поле мощности** | User Code из Smart Life, отсканировать QR |
| 7 | ставит службу автозапуска и запускает бота | — |

Через 5–10 минут в Telegram придёт «🤖 **Мониторинг запущен**».

> 🔁 Изменить настройки потом: снова запустите `~/deye-tg/install.sh` — текущие значения подставятся сами.

<details>
<summary><b>🛠 Ручная установка (если мастер не подошёл)</b></summary>

### 1️⃣ Подготовить Raspberry Pi

1. Запишите на карту **Raspberry Pi OS Lite (64-bit)** через [Raspberry Pi Imager](https://www.raspberrypi.com/software/). В настройках Imager задайте имя пользователя, Wi-Fi и включите SSH.
2. Включите Pi и зайдите по SSH: `ssh пользователь@raspberrypi.local`.
3. Поставьте git:
   ```bash
   sudo apt update && sudo apt install -y git python3-venv
   ```

### 2️⃣ Скачать бота

```bash
git clone https://github.com/famofa24/deye-telegram-bot.git ~/deye-tg
cd ~/deye-tg
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env && chmod 600 .env
```

### 3️⃣ Создать Telegram-бота

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и получите **токен**.
2. Напишите своему новому боту любое сообщение.
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": 123456789` — это ваш **chat_id**.
4. Впишите токен в `.env` скрытым вводом, чтобы он не остался в истории терминала:
   ```bash
   read -rsp 'Токен: ' T && sed -i "s|^TG_TOKEN=.*|TG_TOKEN=$T|" .env && unset T && echo OK
   ```
   А `TG_CHAT_ID` впишите в `.env` вручную: `nano .env`.

### 4️⃣ Найти Wi-Fi-стик инвертора

1. **Серийный номер стика** написан на наклейке самого стика (не инвертора), обычно 10 цифр.
2. **IP стика** посмотрите в списке устройств роутера. Сразу **закрепите его** (DHCP-резерв), чтобы он не менялся.
3. Проверьте, что порт открыт:
   ```bash
   nc -zv <IP_стика> 8899        # должно быть "succeeded"
   ```
4. Впишите `LOGGER_IP` и `LOGGER_SN` в `.env`.

### 5️⃣ Заполнить остальные настройки

Откройте `nano .env` и пройдитесь по разделам. Главное:

| Переменная | Что вписать |
|---|---|
| `YASNO_GROUP` | ваша черга с [yasno.ua](https://yasno.ua), например `3.1`. Пусто — без графика |
| `BATTERY_KWH` | ёмкость батареи, кВт·ч |
| `MIN_SOC` | **Shutdown SOC** из настроек батареи инвертора |
| `TARIFF_DAY`, `TARIFF_NIGHT` | тариф, грн/кВт·ч. Однозонный — одинаковые числа |
| `NIGHT_FROM`, `NIGHT_TO` | часы ночного тарифа (по умолчанию 23–7) |
| `MAIN_BREAKER_A` | вводной автомат квартиры, А (для строки «из 25 А») |

Полный список — ниже, в разделе «⚙️ Настройки».

### 6️⃣ Проверить

```bash
set -a; . ./.env; set +a
.venv/bin/python deye_tg.py --test     # должны появиться напряжение сети, SOC, нагрузка
.venv/bin/python deye_tg.py --yasno    # окна отключений по вашей черге
.venv/bin/python deye_tg.py --demo     # бот пришлёт в Telegram все виды сообщений на выдуманных данных
```

> Если в `--test` заряд батареи — положительное число, а разряд — отрицательное, поставьте `BATT_INVERT=1`.

### 7️⃣ Запустить как службу

Бот будет стартовать сам при включении Pi и перезапускаться при сбоях:

```bash
mkdir -p ~/.config/systemd/user && cp deye-tg.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now deye-tg
sudo loginctl enable-linger $USER        # чтобы работал без входа в систему
systemctl --user status deye-tg          # должно быть active (running)
```

В Telegram придёт «🤖 **Мониторинг запущен**». Готово 🎉

## 🔥 Подключить бойлер и датчики (Tuya)

Аккаунт разработчика Tuya **не нужен**: вход делается по QR-коду, как в Home Assistant.

1. Добавьте розетку и датчики в приложение **Smart Life** (или Tuya Smart). Закрепите IP розетки в роутере.
2. В Smart Life: **Я → ⚙️ Настройки → Аккаунт и безопасность → User Code**. Скопируйте код.
3. На Pi запустите:
   ```bash
   cd ~/deye-tg && set -a; . ./.env; set +a
   .venv/bin/python tuya_login.py <User Code>
   ```
4. Бот пришлёт в Telegram **QR-код**. В Smart Life: вкладка **«Я» → значок сканера** вверху → подтвердите вход.
5. Скрипт сохранит ключи устройств в `devices.json` и токен облака в `data/tuya_token.json`. Оба файла в git не попадают.

**Для бойлера** нужны ещё IP и версия протокола розетки:

```bash
.venv/bin/python -m tinytuya scan        # IP и версия (3.3 / 3.4 / 3.5) каждой розетки
```

Посмотрите, в каком поле розетка отдаёт мощность (включите бойлер, чтобы он грел):

```bash
.venv/bin/python - <<'EOF'
import json, tinytuya
d = next(x for x in json.load(open("devices.json")) if x["name"] == "Бойлер")   # имя как в Smart Life
dev = tinytuya.OutletDevice(d["id"], "IP_розетки", d["key"], version=3.5)      # версия из scan
print(dev.status())
EOF
```

Мощность — это число в десятых долях ватта (например, `13866` = 1386,6 Вт). Обычно это поле `19`, у T34-Smart Plug+ — `22`.

Впишите в `.env`:

```ini
BOILER_ID=bf0123456789abcdefxxxx   # id из devices.json
BOILER_IP=192.168.1.34
BOILER_VERSION=3.5
BOILER_POWER_DP=22
```

И перезапустите: `systemctl --user restart deye-tg`.

**Датчики температуры** подхватятся сами после `tuya_login.py`. Лишние можно скрыть: `CLIMATE_HIDE="Серверная, Гараж"`.

## 🛠 Если что-то не работает

| Симптом | Что сделать |
| --- | --- |
| `--test`: Connection refused / таймаут | проверить IP стика и порт 8899 (`nc -zv`). На новых прошивках порт бывает закрыт: нужна прошивка стика с открытым портом |
| `NoSocketAvailableError` | стик держит **одно** подключение: остановите службу (`systemctl --user stop deye-tg`) перед ручным `--test` |
| Заряд показывается как разряд | `BATT_INVERT=1` |
| `telegram HTTP Error 401` | неверный токен |
| Кнопки не отвечают, `409 Conflict` | запущены два экземпляра бота с одним токеном |
| «Батарея не заряжается» после включения света | включить Grid Charge и проверить Time of Use в инверторе |
| «Свет пропал / появился» подряд | увеличить `CONFIRM` или снизить `GRID_V_MIN` |
| Бойлер: «нет связи с розеткой» | проверить IP и версию (`tinytuya scan`), закрепить IP в роутере. Если в доме несколько точек Wi-Fi с одним именем, Pi может оказаться на той, откуда розетки не видно — лучше подключить Pi кабелем к роутеру |
| Бойлер «обесточен — света нет» | это нормально: розетка подключена к сети мимо инвертора и без света выключена |
| Пришло «Нет связи с инвертором», а он выключен специально | нажать «🔌 Это я выключил» — бот не будет беспокоить до включения |
| `/climate`: «Вход в Tuya не настроен» | запустить `tuya_login.py` (раздел про Tuya выше) |

Лог: `/logs` в Telegram или `journalctl --user-unit deye-tg -n 50 --no-pager -o cat`.

## 🧩 Как это устроено

- **Инвертор:** протокол Solarman V5 на порту 8899 ([pysolarmanv5](https://github.com/jmccrohan/pysolarmanv5)). Регистры Deye SG0xLP1: 150–194 — сеть, батарея, нагрузка; 59–106 — состояние, ошибки, дневные счётчики; 322–323 — BMS. Wi-Fi у стиков слабый, поэтому есть проверка правдоподобия чтений и фильтр скачков SOC.
- **История:** раз в минуту пишется в `data/history.db` (SQLite, ~15 МБ в год). Бойлер — раз в 30 секунд, климат — раз в 10 минут.
- **График отключений:** API ЯСНО, кэш в `data/yasno.json`.
- **Бойлер:** локально через [tinytuya](https://github.com/jasonacox/tinytuya), без интернета; если розетка не видна в локальной сети (другая точка Wi-Fi) — запасной путь через облако Tuya. Опрашивается независимо от инвертора.
- **Климат:** облако Tuya через [tuya-device-sharing-sdk](https://github.com/tuya/tuya-device-sharing-sdk), тот же механизм, что в Home Assistant, плюс подписка MQTT для датчиков, которые облако не описывает.
- **Деньги:** по дневным счётчикам инвертора: из сети + разряд батареи = квартира + заряд батареи + сам инвертор; бойлер — по розетке. Всё делится на день и ночь по тарифу.
- **Сумма из сети** в `/status` — по мощности сети инвертора (регистр 169), она точнее нагрузки и включает собственное потребление инвертора.
- **Надёжность:** если пропал интернет, сообщения копятся и уходят позже с реальным временем события.

### 🔒 Приватность

Данные инвертора и бойлера никуда не уходят из домашней сети. Наружу идут только сообщения в ваш Telegram, запросы графика ЯСНО и, если подключены датчики, облако Tuya. Секреты (`.env`, `devices.json`, `data/`) в git не попадают.
